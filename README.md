# Expense Tracker — Python

Proyecto académico sencillo para registrar gastos personales desde la terminal.

## Funciones
- Agregar gastos con descripción, categoría, monto y fecha.
- Mostrar todos los gastos.
- Consultar el total gastado.
- Ver el total por categoría.
- Guardar los registros automáticamente en `expenses.csv`.

## Requisitos
- Python 3.10 o superior.
- No necesita instalar librerías externas.

## Cómo ejecutarlo
Abre una terminal dentro de esta carpeta y ejecuta:

```bash
python main.py
```

El programa crea `expenses.csv` automáticamente cuando agregas el primer gasto.

## Conceptos practicados
Funciones, listas, diccionarios, validación de datos, manejo de archivos CSV y fechas.

Proyecto desarrollado con fines académicos.
